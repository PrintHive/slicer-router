Slicer Router

Opens each .3mf in the slicer that made it.

Slicer for files with no origin

No supported slicer found. Install Bambu Studio, OrcaSlicer, Snapmaker Orca or PrusaSlicer.

Make Slicer Router the default .3mf app

  1. In Finder, select any .3mf file and press Cmd+I.
  2. Under Open with, choose Slicer Router.
  3. Click Change All….
  1. Open Settings > Apps > Default apps.
  2. Search for .3mf.
  3. Choose Slicer Router.
  4. In each slicer's preferences, turn off Associate .3mf files. Otherwise it takes .3mf back the next time it starts.
